# 分类树与自动成员列表

本机 MediaWiki 已启用自带的 CategoryTree 扩展。「词条树」页面和左侧导航入口通过分类关系自动展示页面。现有正文均保留，分类标签只改变浏览关系。

初始结构有两个方向：

```text
词条总目录
├─ 按模组
│  ├─ 鼠族资料
│  │  ├─ 鼠族武器 → 鼠族/武器与今后添加的具体武器词条
│  │  ├─ 鼠族基因 → 鼠族/基因与今后添加的具体基因词条
│  │  └─ 其他现有主题
│  └─ 沃芬族、米利拉族、美狐族、绮罗族、月兔族资料
└─ 按内容类型
   ├─ 武器 → 鼠族武器 → 同一批武器词条
   ├─ 基因 → 鼠族基因 → 同一批基因词条
   └─ 种族、科技、派系、事件、叙事者等
```

## 在网页修改关系

1. 给元素添加标签：打开元素页，点「编辑」，在可视化编辑器的「页面选项 → 分类」中添加或移除分类，再保存。
2. 改上下级：打开要移动的分类页，用同样的方法修改它的父分类。可以有多个父分类，请避免形成循环。
3. 创建新元素：搜索并创建具体名称的页面，填写内容，再添加适用分类。例如 `鼠族/武器/具体名称` 添加 `鼠族武器` 后，会自动出现在这条分类分支。

源代码中，`[[Category:鼠族武器]]` 表示归入分类；`[[:Category:鼠族武器|鼠族武器]]` 只是一个可点击链接。

普通分类页面底部的列表只显示直接成员，子分类的后代通过成员树逐层展开。分类树每一节点的显示数量有限；成员多时使用分类页的标准分页列表。页面不会从尚未录入的模组内容中自动生成元素。

## 部署配置

在正式服务器的 `LocalSettings.php` 中启用：

```php
wfLoadExtension( 'CategoryTree' );
$wgCategoryTreeMaxDepth = [0 => 3, 10 => 3, 20 => 3, 100 => 2];
```

`词条树.wiki` 和 `分类与词条关系.wiki` 是初始页面源码，`分类关系初始快照.json` 记录初始分类对应关系。实际分类关系在本机数据库中维护，网页编辑不会自动同步到 GitHub；迁移时应导出词条、分类页面及上述帮助页。

[CategoryTree 官方文档](https://www.mediawiki.org/wiki/Extension:CategoryTree/zh)

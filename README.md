# 边缘世界模组维基

面向中文玩家的 RimWorld 社区种族模组资料站。首期收录鼠族、沃芬族、米利拉族、美狐族、绮罗族与月兔族。

网站采用传统百科页面布局：首页、分类页、条目正文、右侧信息框、章节目录、参考资料和站内搜索。本站是托管在 GitHub Pages 上的静态网站；条目的修订通过 GitHub 完成，页面的源代码与历史记录入口会打开对应的数据文件。

真正的 MediaWiki 迁移资料见 `mediawiki/`。该目录包含可导入的六个种族条目与首页；新 Wiki 建立后，条目将通过 MediaWiki 的可视化编辑器维护。

## 本地预览

在项目目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。项目没有构建步骤。

## 修改条目

六个种族的数据位于 `src/data.js` 的 `races` 数组。每个条目记录名称、工坊来源、游戏版本、前置模组、DLC、简介、内容要点与相关扩展。页面布局和搜索逻辑位于 `src/app.js`，样式位于 `styles.css`。

欢迎通过 GitHub Issues 报告错误，或提交 Pull Request 修改数据。请附原始来源、适用游戏版本和核对日期。

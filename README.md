# 边缘种族档案 · RimWorld 社区模组 Wiki

面向中文玩家整理 RimWorld 社区种族模组的静态 Wiki。首期收录鼠族、沃芬族、米利拉族、美狐族、绮罗族与月兔族。

## 本地预览

本项目不依赖构建工具或第三方 JavaScript 库。使用任意静态文件服务器预览即可，例如在项目目录运行 `py -m http.server 8000`，再访问 `http://localhost:8000`。

## 添加或修改专题

编辑 `src/data.js` 中的 `races` 数组。每个种族条目包含工坊链接、版本、前置模组、DLC、特色、扩展列表和来源说明。新增专题时为其指定唯一的 `id`，并在 `categories` 中按需加入筛选类别。

## 参与贡献

欢迎通过 GitHub Issues 报告错误和缺漏，或提交 Pull Request。请附上原始来源、游戏版本及核对日期；未经复核的兼容性报告应标为玩家反馈。

## 来源与素材

模组信息摘要来自对应作者公开的 Steam 工坊页面或作者维护页面，页面中提供原始链接。模组名称、商标、游戏内容、美术与其他作品均属于各自权利人。本项目不托管或重新分发模组文件及未经授权的模组素材。

本站参考 RimWorld 中文 Wiki 的分类导航和社区协作方式，内容与视觉设计独立编写；本站与 Ludeon Studios、灰机 Wiki 及所收录模组作者没有隶属关系。
